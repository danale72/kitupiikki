# Security policy

Kiswas PG is an unofficial fork of [artoh/kitupiikki](https://github.com/artoh/kitupiikki).
Kitsas Oy does not support this software and is not the place to report problems in this fork.

## Reporting a vulnerability

Report a vulnerability in this repository through
[GitHub private vulnerability reporting](https://github.com/danale72/kitupiikki/security/advisories/new),
or by opening a GitHub issue if the report contains no secrets, exploit detail, or private data.

Please include the version or commit, what is affected, and how to reproduce the problem.
Do not include database files, credentials, or customer data.

# Tietoturva

Kiswas PG on epävirallinen versio ohjelmasta
[artoh/kitupiikki](https://github.com/artoh/kitupiikki).
Kitsas Oy ei tue tätä ohjelmistoa, eikä haavoittuvuuksia tule ilmoittaa heille.

## Haavoittuvuuden ilmoittaminen

Ilmoita haavoittuvuus tämän tietovaraston
[GitHubin yksityisellä ilmoituksella](https://github.com/danale72/kitupiikki/security/advisories/new).
Jos ilmoitus ei sisällä salaisuuksia, hyväksikäyttöohjeita tai yksityisiä tietoja,
voi avata myös GitHub-issuen.

Kerro versio tai commit, mitä vika koskee ja miten sen voi toistaa.
Älä liitä mukaan tietokantatiedostoja, tunnuksia tai asiakastietoja.
